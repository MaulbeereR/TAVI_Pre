

# **TAVI智能分析系统 (TAVI-AISys)**

本项目是一个集成了大型语言模型（LLM）的TAVI数据高级分析与智能问答平台。它旨在通过自然语言交互，赋能临床医生，简化数据筛选流程，并提供基于海量病例文献的深度追问能力。

---

### **核心功能** ✨

1.  **知识库问答 (基本完成)**
    *   **描述**: 基于TAVI指南和专家共识，提供精准的医疗知识问答。
    *   **实现**: 用户在前端悬浮球中提问，由后端的RAGFlow知识库提供答案。

2.  **自然语言筛选 (基本完成)**
    *   **描述**: 用户使用自然语言（如“找出所有LVEF小于40%的高龄女性患者”）直接驱动整个页面的数据和图表进行筛选更新。
    *   **实现**: `自然语言 -> LLM -> SQL语句 -> Python -> 前端筛选JSON -> UI更新`。

3.  **多病例追问 (待开发)**
    *   **描述**: 在数据筛选后，支持对一个或多个病例的原始文献进行深度提问，由AI进行综合分析并生成答案。
