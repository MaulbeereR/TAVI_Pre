## 🔍 冷门字段识别和扩展流程

### 1. 识别冷门字段的方法

#### 通过日志分析
监控系统日志中的错误信息，特别关注：
```bash
Not supported query type: [AI返回的查询内容]
```

#### 常见的冷门字段类型
1. **复合医学术语** - 如"出院前死亡（心力衰竭）"
2. **程度描述词** - 如"中度以上"、"轻微"、"显著"
3. **时间限定词** - 如"术后即刻"、"随访期间"
4. **专业缩写** - 如"PVL"、"STJ"、"LVOT"
5. **同义表达** - 如"瓣周反流"vs"瓣周漏"

### 2. 扩展知识库的步骤

#### 步骤1: 添加新的字段映射
在 `data/tavi_field_mapping.json` 中的相应分类下添加：

```json
{
  "field_mappings": {
    "分类名称": {
      "中文医学术语": "对应的数据库字段名",
      "同义词1": "对应的数据库字段名",
      "同义词2": "对应的数据库字段名"
    }
  }
}
```

#### 步骤2: 更新复合查询模板
对于复杂的多条件查询，在 `complex_queries` 部分添加：

```json
{
  "complex_queries": {
    "query_key": {
      "description": "查询描述",
      "conditions": [
        {"field": "字段名1", "value": true},
        {"field": "字段名2", "operator": ">", "value": 75}
      ]
    }
  }
}
```

#### 步骤3: 扩展同义词映射
在 `synonyms_mapping` 中添加：

```json
{
  "synonyms_mapping": {
    "主术语": ["同义词1", "同义词2", "英文术语"],
    "程度词": ["中度以上", "≥中度", "中重度"]
  }
}
```

#### 步骤4: 更新数据类型信息
确保新字段在相应的数据类型数组中：

```json
{
  "data_type_info": {
    "boolean_fields": ["新的布尔字段"],
    "numeric_fields": ["新的数值字段"],
    "categorical_fields": ["新的分类字段"]
  }
}
```

### 3. 前端UI映射扩展

在 `app.js` 的 `applyFiltersToUI` 函数中添加对新字段的支持：

```javascript
// 布尔值字段映射
const booleanMapping = {
  'new_field_name': { 
    id: 'html-element-id', 
    name: '显示名称', 
    type: 'category_type' 
  }
};

// 数值范围字段映射
const numericMapping = {
  'new_numeric_field': {
    minId: 'min-input-id',
    maxId: 'max-input-id', 
    name: '字段显示名称',
    unit: '单位'
  }
};
```

### 6. 最佳实践

#### 命名规范
- **中文术语**: 使用标准医学术语
- **数据库字段**: 使用英文小写+下划线格式
- **HTML ID**: 使用连字符分隔的小写格式

#### 映射策略
1. **一对多映射**: 多个中文术语指向同一个数据库字段
2. **程度映射**: 将不同程度描述映射到相同的布尔字段
3. **时间映射**: 将时间限定词作为字段前缀处理

#### 性能优化
- 保持映射表简洁，避免重复
- 使用索引优化查找性能
- 定期清理无用的映射项

### 7. 故障排除

#### 常见问题
1. **字段未映射**: 检查字段名是否在知识库中
2. **UI未更新**: 确认前端映射代码已更新
3. **复合查询失败**: 检查复合查询模板格式

#### 调试技巧
- 查看浏览器控制台日志
- 检查网络请求中的知识库数据
- 使用验证脚本检查JSON格式

### 8. 更新部署

#### 热更新支持
知识库文件支持热更新，无需重启服务：
1. 修改 `data/tavi_field_mapping.json`
2. 刷新页面即可加载新的映射

#### 版本控制
建议为每次重大更新创建备份：
```bash
cp data/tavi_field_mapping.json data/tavi_field_mapping_backup_$(date +%Y%m%d).json
```
