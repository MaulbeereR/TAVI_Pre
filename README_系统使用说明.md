# TAVI智能分析系统使用说明

## 1. 系统概述

TAVI智能分析系统是一个专门用于经导管主动脉瓣置换术(TAVI)数据分析的Web应用系统。该系统提供了直观的数据筛选、统计分析和可视化功能，帮助医疗专业人员更好地理解和分析TAVI手术相关数据。

## 2. 系统部署

### 2.1 环境要求
- Python 3.8+
- MySQL 8.0+
- 现代浏览器（Chrome、Firefox、Safari、Edge等）

### 2.2 安装步骤

1. 克隆代码仓库
```bash
git clone [仓库地址]
cd TAVI_Pre
```

2. 安装Python依赖
```bash
pip install -r requirements.txt
```

3. 配置数据库
- 创建MySQL数据库
- 执行`create_tavi_database.sql`脚本创建数据库结构
- 修改`import_tavi_data.py`中的数据库连接配置：
  ```python
  host='139.196.16.111'
  user='root'
  password='qzoVLyLcMWMA2cL5'
  database='tavi_data'
  ```

4. 导入数据
```bash
python import_tavi_data.py [JSON数据文件路径]
```

### 2.3 启动系统

1. 启动Web服务器
```bash
python app.py
```

2. 访问系统
- 打开浏览器
- 访问 http://localhost:5000

## 3. 系统功能

### 3.1 数据筛选
系统提供多维度的数据筛选功能，包括：
- 基线资料筛选
- 术前影像学评估筛选
- 手术信息筛选
- 出院前评价筛选
- 随访信息筛选

### 3.2 数据展示
系统提供两种数据展示模式：
- 图表分析视图：通过各类统计图表直观展示数据分布和趋势
- 详细数据视图：以表格形式展示具体病例数据

### 3.3 数据导出
支持将筛选后的数据导出为Excel格式，方便进一步分析。

## 4. 使用指南

### 4.1 数据筛选操作
1. 在筛选面板中选择需要筛选的条件
2. 对于数值型数据，可以设置最小值和最大值范围
3. 对于分类数据，可以选择多个选项
4. 点击"应用筛选"按钮执行筛选
5. 点击"重置"按钮清除所有筛选条件

### 4.2 图表分析
系统提供以下统计图表：
- 年龄分布图
- NYHA分级分布图
- 瓣膜直径分布图
- 术前术后指标对比图
- 并发症发生率图

### 4.3 详细数据查看
1. 切换到"详细数据"视图
2. 可以查看每个病例的基本信息
3. 点击"查看详情"可以查看病例的完整信息
4. 使用分页控件浏览更多数据

### 4.4 数据导出
1. 在详细数据视图中点击"导出数据"按钮
2. 选择保存位置
3. 导出的Excel文件包含当前筛选条件下的所有数据

## 5. 注意事项

1. 所有数值型数据的单位已标注在字段名称后
2. 部分筛选条件默认折叠，可以通过"更多"按钮展开
3. 图表支持配色方案切换
4. 数据导出功能仅支持导出当前筛选条件下的数据

## 6. 系统要求

- 支持现代浏览器（Chrome、Firefox、Safari、Edge等）
- 建议使用1920x1080或更高分辨率显示器
- 需要稳定的网络连接

## 8. 常见问题

### 8.1 数据库连接问题
- 检查数据库服务是否正常运行
- 验证数据库连接配置是否正确
- 确保数据库用户具有适当的权限

### 8.2 数据导入问题
- 确保JSON数据文件格式正确
- 检查数据文件路径是否正确
- 查看导入日志了解详细错误信息

### 8.3 系统访问问题
- 确保Web服务器正常运行
- 检查防火墙设置
- 验证端口是否被占用
